# 🗄 SQL

В данном разделе представлены проекты по анализу данных с использованием SQL.

Проекты посвящены решению прикладных аналитических задач, работе с реляционными базами данных, исследованию пользовательского поведения, анализу бизнес-показателей и подготовке аналитических рекомендаций.

| № | Проект | Описание | Стек |
|:-:|---------|----------|-------|
| 1 | [Исследование внутриигровых покупок](./01-game-analytics/) | Исследование поведения игроков, анализ факторов, влияющих на покупку внутриигровой валюты и эпических предметов, а также подготовка рекомендаций по повышению монетизации игрового продукта. | PostgreSQL |
| 2 | [Исследование рынка недвижимости Санкт-Петербурга и Ленинградской области](./02-real-estate-analysis/) | Исследование рынка жилой недвижимости, анализ привлекательности сегментов, сезонности продаж и подготовка рекомендаций для формирования стратегии выхода агентства на новый рынок. | PostgreSQL, [DataLens](https://datalens.yandex/hs5ifm84sy5q1) |
