# 🗄 SQL

В данном разделе представлены проекты по анализу данных с использованием SQL.

Проекты посвящены решению прикладных аналитических задач, работе с реляционными базами данных, исследованию пользовательского поведения, анализу бизнес-показателей и подготовке аналитических рекомендаций.

| № | Проект | Описание | Стек |
|:-:|---------|----------|-------|
| 1 | [Исследование внутриигровых покупок](./01-game_analytics/) | Исследование поведения игроков, анализ факторов, влияющих на покупку внутриигровой валюты и эпических предметов, а также подготовка рекомендаций по повышению монетизации игрового продукта. | PostgreSQL |
| 2 | [Исследование рынка недвижимости Санкт-Петербурга и Ленинградской области](./02-real_estate_analysis/) | Исследование рынка жилой недвижимости, анализ привлекательности сегментов, сезонности продаж и подготовка рекомендаций для формирования стратегии выхода агентства на новый рынок. | PostgreSQL, [DataLens](https://datalens.yandex/hs5ifm84sy5q1) |
| 3 | [Расчёт и визуализация ключевых бизнес-метрик сервиса доставки еды](./03-food_delivery_business_metrics/) | Анализ динамики клиентской базы и ключевых бизнес-метрик сервиса доставки еды. Рассчитаны и визуализированы DAU, конверсия, средний чек, LTV и Retention Rate для оценки активности пользователей, эффективности конверсии и удержания клиентов. | PostgreSQL, [DataLens](https://datalens.yandex/93dfi3oyc8g8s)|
| 4 | [Рынок вакансий и требования к аналитикам](./04-hh_analytics_job_market/) | Анализ рынка вакансий для оценки уровня заработных плат, географии спроса, работодателей, условий занятости и распределения грейдов. Исследована востребованность hard и soft skills для определения ключевых требований рынка к аналитикам. | PostgreSQL |
| 5 | [Активность и вовлечённость доноров](./05-donorsearch_analysis/) | Анализ активности доноров и факторов, связанных с регулярностью донаций. Исследованы география доноров, динамика донаций, активность пользователей, влияние бонусной системы и эффективность каналов привлечения для выявления возможностей повышения вовлечённости. | PostgreSQL |
