# 🐍 Python

В данном разделе представлены проекты по анализу данных, выполненные с использованием Python.

Проекты охватывают различные аналитические задачи: исследовательский анализ данных (EDA), предобработку данных, визуализацию, проверку статистических гипотез и подготовку аналитических выводов.

| № | Проект | Описание | Стек |
|:-:|---------|----------|-------|
| 1 | [Исследование развития игровой индустрии](./01-video_game_market_analysis.ipynb) | Исследование развития игровой индустрии, выявление ключевых тенденций рынка, наиболее популярных платформ, игровых жанров и региональных предпочтений пользователей. | Pandas |
| 2 | [Исследование рынка заведений общественного питания Москвы](./02-moscow_restaurants_analysis.ipynb) | Исследовательский анализ рынка общественного питания Москвы для выявления особенностей рынка и подготовки рекомендаций по выбору формата и локации будущего заведения. | Pandas, Matplotlib, Seaborn, Phik |
| 3 | [Исследование финансирования стартапов](./03-startup_analysis.ipynb) | Исследование исторических данных о финансировании стартапов, анализ инвестиционных тенденций и подготовка рекомендаций по наиболее перспективным направлениям инвестирования. | Pandas, Matplotlib, Seaborn |
| 4 | [Анализ пользовательского поведения и статистическая проверка бизнес-гипотез](./04-business_hypotheses_analysis.ipynb) | Анализ поведения пользователей с подпиской и без подписки, оценка экономической ценности сегментов и статистическая проверка бизнес-гипотез для поиска точек роста выручки. | Pandas, Matplotlib, SciPy |
| 5 | [A/B-тестирование влияния нового алгоритма рекомендаций](./05-ab-testing-analysis.ipynb) | Проверка гипотезы о влиянии нового алгоритма рекомендаций на вовлечённость пользователей. Проведение A/B-теста, оценка различий между группами и статистическая проверка результатов для принятия решения о внедрении алгоритма. | Pandas, NumPy, Matplotlib, Seaborn, Statsmodels |
