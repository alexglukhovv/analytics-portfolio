# 🐍 Python

В данном разделе представлены проекты по анализу данных, выполненные с использованием Python.

Проекты охватывают различные аналитические задачи: исследовательский анализ данных (EDA), предобработку данных, визуализацию, проверку статистических гипотез и подготовку аналитических выводов.

| № | Проект | Описание | Стек |
|:-:|---------|----------|-------|
| 1 | [Исследование развития игровой индустрии](./video-game-market-analysis/) | Исследование развития игровой индустрии, выявление ключевых тенденций рынка, наиболее популярных платформ, игровых жанров и региональных предпочтений пользователей. | Pandas |
| 2 | [Исследование рынка заведений общественного питания Москвы](./moscow-restaurants-analysis/) | Исследовательский анализ рынка общественного питания Москвы для выявления особенностей рынка и подготовки рекомендаций по выбору формата и локации будущего заведения. | Pandas, Matplotlib, Seaborn, Phik |
| 3 | [Исследование финансирования стартапов](./startup-analysis/) | Исследование исторических данных о финансировании стартапов, анализ инвестиционных тенденций и подготовка рекомендаций по наиболее перспективным направлениям инвестирования. | Pandas, Matplotlib, Seaborn |
