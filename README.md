# 📊 Analytics Portfolio

Добро пожаловать!

В данном репозитории представлены аналитические проекты, отражающие мой профессиональный путь и развитие в области аналитики.

В проектах используются современные инструменты анализа данных, включая Python, SQL, BI, а также методы продуктовой аналитики и A/B-тестирования. Каждый проект содержит описание задачи, используемых инструментов, процесса анализа и полученных результатов.

Репозиторий регулярно пополняется новыми проектами по мере развития профессиональных компетенций.

---

## 🗂 Навигация

### 🐍 [Python](./Python/)

Проекты по анализу и обработке данных.

**Инструменты:** Pandas, Matplotlib, Seaborn, SciPy, Numpy, Phik.

### 🗄 [SQL](./SQL/)

Проекты по работе с реляционными базами данных и решению аналитических задач.

**Инструменты:** PostgreSQL, DataLens.

### 📊 [BI](./BI/)

Проекты по визуализации данных и разработке аналитических дашбордов.

**Инструменты:** DataLens.

---

# 📌 Что включает каждый проект

Каждый проект содержит:

- описание бизнес-задачи;
- описание исходных данных;
- используемые инструменты;
- процесс анализа и ключевые этапы исследования;
